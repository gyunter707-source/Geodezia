# Geodezia - Конвертер тахеометрической съемки в DXF

Программа для преобразования TXT-файла тахеометрической съемки в DXF-файл AutoCAD с пошаговым интерфейсом.

## Возможности

- Пошаговый мастер (wizard) из 5 экранов
- Автоматическое определение групп точек по имени
- Ручное объединение групп в логические слои
- Экспорт точек как CIRCLE с текстовыми подписями
- Отдельные слои для имен точек и Z-отметок
- Работает без интернета

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Сборка в EXE (один файл)

Для создания портативного EXE-файла, который запускается двойным кликом и работает без Python:

### Шаг 1: Установите PyInstaller

```bash
pip install pyinstaller
```

### Шаг 2: Соберите EXE

```bash
pyinstaller --onefile --windowed --name "Geodezia" main.py
```

**Расшифровка параметров:**
- `--onefile` - создаёт один исполняемый файл (всё внутри)
- `--windowed` - не показывает консольное окно при запуске
- `--name "Geodezia"` - имя создаваемого EXE файла

### Шаг 3: Найдите готовый EXE

После выполнения команды появится папка `dist/` в папке с программой.

```
geodezia/
├── dist/
│   └── Geodezia.exe    <-- Готовый EXE файл!
├── build/
├── Geodezia.spec
└── ... остальные файлы проекта
```

## Использование готового EXE

1. Скопируйте `Geodezia.exe` из папки `dist/` в любое место (например, на флешку)
2. Запустите двойным кликом - Python не требуется!
3. Программа работает полностью автономно

## Пошаговое использование

### Экран 1 - Загрузка TXT
Нажмите "Выбрать TXT файл" и укажите файл с данными тахеометрии.

### Экран 2 - Настройка координат
Выберите числовые значения X, Y, Z из примера. Программа определит колонки автоматически.

### Экран 3 - Объединение групп
Просмотрите найденные группы (буквенная часть имени точки).
Для объединения групп введите одинаковое имя в колонку "Итоговая группа".
Дважды кликните по ячейке для редактирования.

### Экран 4 - Названия слоёв
Задайте понятные имена слоёв для AutoCAD.
Дважды кликните по ячейке для редактирования.

### Экран 5 - Экспорт
Нажмите "Сохранить DXF файл" и выберите место для сохранения.

## Формат входного TXT файла

```
ИМЯ_ТОЧКИ,X,Y,Z,
```

Пример:
```
K1,100.5,200.3,50.2,
K2,105.2,198.7,51.0,
NIZR4,500.1,300.4,45.0,
```

Имя точки: буквенный префикс + цифры (например: K1, NIZR12, ST3)

## Результат в DXF

Для каждой точки создаются:
1. **CIRCLE** - окружность радиусом 0.05
2. **POINT** - точка в центре окружности
3. **Текст с именем** - слой с суффиксом `_NAMES` (красный)
4. **Текст с Z-отметкой** - слой с суффиксом `_Z` (зеленый)

Слои в DXF:
- `{имя_слоя}` - точки и круги
- `{имя_слоя}_NAMES` - имена точек
- `{имя_слоя}_Z` - Z-отметки
